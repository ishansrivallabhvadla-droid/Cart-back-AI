Absolutely. Since you're on Windows, let's run the NudgeFlow production backend step-by-step and make sure it works properly before connecting real WhatsApp/AI/payment services.

You already have the ZIP:

1. Extract the ZIP

Extract it somewhere simple, for example:

C:\NudgeFlow

After extraction, you should have:

C:\NudgeFlow\nudgeflow\

Inside nudgeflow, you should see:

app.py
.env.example
README.md
requirements.txt
app\
templates\

Important: Open the terminal in the folder containing app and requirements.txt.

2. Check Python

Open Command Prompt and run:

bat
python --version

You should see Python 3.x.

If python isn't recognized, try:

bat
py --version

If you don't have Python installed, install it from the official Python website:

Python Downloads

During installation, make sure "Add Python to PATH" is checked.

3. Open the NudgeFlow folder

In Command Prompt:

bat
cd C:\NudgeFlow\nudgeflow

Then verify:

bat
dir

You should see something similar to:

app
app.py
.env.example
README.md
requirements.txt
templates

4. Create a virtual environment

Run:

bat
python -m venv .venv

Then activate it:

bat
.venv\Scripts\activate

Your terminal should now look something like:

(.venv) C:\NudgeFlow\nudgeflow>

That (.venv) is important.

5. Install the backend dependencies

Run:

bat
python -m pip install --upgrade pip

Then:

bat
pip install -r requirements.txt

This installs the backend components including:

  • FastAPI

  • Uvicorn

  • SQLAlchemy

  • Pydantic Settings

  • APScheduler

  • HTTPX

  • Jinja2

6. Create the .env file

Copy the example:

bat
copy .env.example .env

Then open it:

bat
notepad .env

For your first run, you can leave it in demo mode.

The important settings are:

env
ENVIRONMENT=development
DATABASE_URL=sqlite:///./nudgeflow.db

FOLLOWUP_DELAY_MINUTES=30
MAX_FOLLOWUPS=2
INTENT_THRESHOLD=0.55

SCHEDULER_ENABLED=true

WEBHOOK_VERIFY_TOKEN=replace-this

MODEL_PROVIDER=rules

Don't put real WhatsApp/payment credentials in the demo.

7. Start NudgeFlow

Run:

bat
uvicorn app.main:app --reload

You should see something like:

INFO:     Uvicorn running on http://127.0.0.1:8000

Keep this Command Prompt open.

8. Open the dashboard

Open Chrome and go to:

NudgeFlow Dashboard

You should see the NudgeFlow owner dashboard.

9. Open the Customer ↔ AI interface

Go to:

Customer AI Chat

Enter something like:

Name: Ishan
Phone: 9999999999
Message: I'll buy later, can you send me the payment link?

The backend should analyze the message.

The important flow is:

Customer message
       ↓
FastAPI
       ↓
Intent Engine
       ↓
Purchase intent detected
       ↓
Intent score
       ↓
Lead created
       ↓
30-minute follow-up scheduled

NudgeFlow API Documentation

⚠️ One important thing about the current backend

The current ZIP is production-style, but it is intentionally configured for a safe local demo.

It currently uses:

SQLite
   +
Rules-based Intent Engine
   +
Local APScheduler
   +
Simulated Payment
   +
WhatsApp adapter

For a real deployment, we should upgrade those pieces to:

PostgreSQL
      +
Real LLM Intent Classifier
      +
Redis + Celery
      +
Razorpay/Stripe
      +
WhatsApp Business Cloud API

And add:

Authentication
RBAC
Rate limiting
Alembic migrations
Structured logging
Webhook idempotency
Automated tests
HTTPS
Production secrets

If you want the perfect hackathon setup, don't connect all of those immediately.

First get this working:

/ → /chat → /docs → intent detection → lead → scheduler → payment click → recovery dashboard.

Once that works, we can connect the real WhatsApp Business API and real AI model without breaking your working demo.
